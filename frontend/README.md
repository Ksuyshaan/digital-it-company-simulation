# Digital IT Company Simulation — фронтенд

SPA для дисциплины «Лидерство в IT»: студенты 15 недель работают как IT-компания (ТЗ и макеты — в корне репозитория).
React 18 + TypeScript + Vite, без сторонних UI-библиотек.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
```

Бэкенда пока нет: данные — демо-курс (96 студентов, 22 команды), создаются при первом запуске
и хранятся в `localStorage` браузера. Кнопка **«Демо»** (правый нижний угол) — вход под любой ролью,
сценарий «окно формирования команд», сброс данных.
Откройте две вкладки под разными ролями — сообщения и изменения доски появляются без перезагрузки.

Вход: «Войти через Microsoft 365» → выбор учётной записи, или ввод почты `@university.kz`.
Почта с другого домена отклоняется.

## Экраны

| Роль | Экраны |
|---|---|
| Студент | Дашборд, Доска задач (Scrum), Чат команды, Профиль и рейтинг, Команды (формирование / заморожены), Задания и peer-review |
| Преподаватель / ассистент | Аналитика (метрики, сигналы, блокировки, экспорт), Команды (утверждение, перевод студентов, балл проекта), Задания и оценки, Рейтинг и ведомость, Все каналы, Журнал действий, Настройки курса, «Вид студента» |
| Администратор | Пользователи и роли, курсы, импорт CSV, вход и домены, состояние системы, журнал |

## Что реализовано из ТЗ

- **Доска (п. 4):** колонки и переходы, Done только из Review и не исполнителем, обязательные поля для To Do+,
  комментарий при возврате из Review, предупреждение о WIP-лимите, архив вместо удаления, история изменений,
  чек-лист (до 20), файлы (до 10, ≤25 МБ, без .exe/.bat/.sh…), @упоминания, спринты (planning, burndown,
  закрытие с отчётом, перенос незавершённых), ретроспектива с оценкой коллег, блокировка «только чтение» (в т.ч. по расписанию).
- **Чат (п. 5):** каналы общий / объявления / команды, ветки, реакции, файлы, редактирование 15 мин
  (преподаватель видит исходный текст), удаление скрывает только от студентов, поиск по тексту/автору/дате
  (преподаватель — по всем каналам), пометка «Переписку видит преподаватель».
- **Оценивание (п. 3.2–3.3, 7):** штраф 10%/сутки, закрытие сдачи через 72 ч, продление, peer-review
  (2 анонимных рецензента, комментарий ≥100 символов, 48 ч, оспаривание), итог 0,7/0,3,
  Р1 = И + А, Р2 = К + П, РД = (Р1 + Р2)/2 — всё считается формулами из `src/lib/rules.ts`.
- **Команды (п. 3.4):** заявки (≤3), приглашения, роли, проверка правил с указанием нарушенного,
  утверждение / возврат / утверждение в обход правил, автораспределение, заморозка.
- **Аналитика (п. 6):** метрики по курсу/команде/студенту за период, 5 автоматических сигналов с настраиваемыми порогами.
- Ручные баллы — только с причиной, попадают в журнал и профиль студента. Экспорт ведомости в Excel (CSV) и PDF (печать).
- Адаптивная вёрстка от 360 px.

## Структура

```
src/
  types.ts            модели данных
  lib/rules.ts        бизнес-правила и формулы ТЗ (рейтинг, штрафы, проверки, сигналы, burndown)
  data/actions.ts     все изменения данных с проверками прав — точки замены на вызовы API
  data/seed.ts        генератор демо-курса
  store.tsx           состояние, сохранение, синхронизация вкладок
  pages/              экраны
  components/         каркас, общие элементы
```

Для подключения бэкенда: заменить `store.tsx` + `data/actions.ts` вызовами REST/WebSocket;
формулы из `lib/rules.ts` можно перенести на сервер один в один.
